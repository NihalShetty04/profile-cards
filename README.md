# Interactive Profile Card System

## Description
This project is a React-based application that displays multiple user profile cards using reusable components. Each card shows user details and includes a follow/unfollow button that updates dynamically based on user interaction. The project focuses on understanding core React concepts and building a clean, modern UI.

## Features
- Reusable ProfileCard component
- Follow / Unfollow toggle functionality
- Dynamic data using props
- Conditional rendering
- Multiple cards rendered using map()
- Responsive and modern UI design

## Technologies Used
- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- Vite
- Node.js & npm
- Git & GitHub

##  How to Run
npm install
